# `mlmf-meta` — Canonical Key Vocabulary and Template/Special-Token Extraction

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A crate that answers "what did this file declare about its chat template and special tokens?" over any `MetadataSource`, without knowing how the bytes were parsed and without deciding what the answer means.

**Architecture:** `mlmf-meta` sits above `mlmf-core` and below every format crate. It holds the §5 canonical-key vocabulary **as a data table**, not as parsing logic, so it depends on no format crate (C4/C7). Extraction takes `&S where S: MetadataSource + ?Sized` plus an explicit `Format`, because a `MetadataSource` does not say what produced it and guessing is interpretation.

**Tech Stack:** Rust 2021, `mlmf-core` only. No `serde`, no I/O, no format crates.

**Spec:** `docs/superpowers/specs/2026-08-14-backend-agnostic-mlmf-design.md` — §5 (canonical key vocabulary), §6 (Declared/Absent/Supplied, CD-1..3), §9 clauses 1 and 4, §12 step 4.

## Global Constraints

Every task's requirements implicitly include this section.

- **C4 / C7 — no format-crate dependency.** `mlmf-meta`'s `[dependencies]` may name `mlmf-core` and nothing else from this workspace. Knowing that GGUF spells a key `tokenizer.chat_template` is a **table row** (§5: "Declared, bidirectional, per-format"); knowing how to find that key in a byte stream is a parser and does not belong here.
- **§5 rule 1 — enumerate what you understand; preserve what you don't.** "Dropping unrecognised keys is the worst kind of lossy — invisible." Every extraction reports what it could not classify rather than discarding it.
- **§5 rule 2 — absent means `None`, never a default** (except under §6).
- **§5 rule 4 / §4.1 — extend by data, not by variants.** The vocabulary is a `const` table. Adding a format or a key is adding a row.
- **§6 CD-1 — a supplied default must be citable** to a specification or named reference implementation, with the citation beside the value. **This crate supplies nothing.** It reports declarations. If a later task is tempted to supply, it needs a citation first.
- **AD-2 — no test is trusted until sabotage has made it go red.** Record the sabotage, the command, and the observed failure text in the task notes. **Verify every mutation actually applied** (`git diff --stat` must show one file changed) — a `sed`/`perl` that matches nothing produces a pass that means nothing, and that is vacuity mode 1.
- **Corpus rule — assert the corpus, and name where it came from.** Every corpus-derived expected value carries, in the test source, the file it came from and the date it was measured at.
- **Skip-condition rule.** A test that skips must (a) write its notice using `mlmf_core::NOTICE_TOKEN`, (b) honour `MLMF_CORPUS_REQUIRED=1` by failing instead of skipping, and (c) **state a skip reason that is itself true.** A justification is a factual claim. A test whose comment says "run with `-- --ignored`" while not carrying `#[ignore]` selects nothing, and libtest prints `0 ignored` either way — filtered-out and never-selected are indistinguishable in the output.
- **`rustfmt` before every commit.** `cargo fmt --all` then `cargo fmt --all -- --check`.
- **Both feature configurations.** C6: CI builds, tests, lints **and documents** with and without default features. A new gated member must appear in every matrix that names members.

```

## The corrected §9 clause 4.1, quoted

The superseded text required, unconditionally:

> `add_special_tokens = false` — the template emits BOS itself.

⚠️ **That describes a defect, not a requirement.** It was an accurate description of Lightbulb's pre-fix code, promoted to a normative rule by being written into a spec with a §14 attribution — and the attribution, normally the thing that makes a decision checkable, is what stopped anyone re-deriving it. Their own account: *"the half I had measured became the whole rule."*

Measured on TinyLlama-1.1B-Chat Q4_0 after lightbulb PR #19:

```
22 ids, no BOS   ->  "France| Paris, France</s>"
23 ids, with BOS ->  "The French capital of France.</s>"
```

**The corrected rule: whether to add BOS is a property of the RENDERED string, which extraction does not produce.** It therefore **cannot be a static field of an extraction result**.

**What this crate does instead, and the distinction that makes both halves true:**

- It **reports the declaration**. `tokenizer.ggml.add_bos_token` is present in 15 of 28 files. It is in the file, so MLMF surfaces it — dropping it would be §5 rule-1 lossy.
- It **does not compute the behaviour**. There is no field named `add_special_tokens`, and no method answering "should I add BOS?". That answer requires the rendered string and belongs to the consumer.

⚠️ **Note for the PM and for lightbulb:** this is a refinement of the shape stated earlier as `{ template, bos, eos, source }` with *no* add-flag. A **declared** `add_bos_token: Option<bool>` is not a computed rule, and omitting a key the file declares would violate §5 rule 1. Both constraints hold together; the earlier one-line summary was too narrow. The difference is visible in the type, so it is stated here rather than left to be discovered.

// crates/mlmf-meta/src/vocab.rs
//! The section 5 canonical key vocabulary, held as data.
//!
//! Spec section 5: "Declared, bidirectional, per-format." Adding a format
//! or a key is adding a row to [`TABLE`], never a new match arm — section
//! 4.1's "extend by data, not by variants" applied to keys.
//!
//! **Knowing that GGUF spells a key `tokenizer.chat_template` is a table
//! row, not format knowledge.** Nothing here parses bytes, which is what
//! keeps C4 true: this crate names no format crate.

/// Which format's spelling to look up.
///
/// A [`MetadataSource`](mlmf_core::MetadataSource) does not say what
/// produced it, so callers pass this explicitly. Inferring the format from
/// the keys present would be exactly the interpretation this crate refuses.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
#[non_exhaustive]
pub enum Format {
    /// GGUF's flat, typed key-value block.
    Gguf,
    /// HuggingFace's JSON sidecars, qualified by filename.
    HuggingFace,
    /// Safetensors' `__metadata__`, which is `string -> string`.
    Safetensors,
}

/// Canonical key names. These are the mlmf-side spelling, never a format's.
pub mod keys {
    /// The default chat template.
    pub const CHAT_TEMPLATE: &str = "tokenizer.chat_template";
    /// The array of ADDITIONAL template names. Never includes the default.
    pub const CHAT_TEMPLATE_NAMES: &str = "tokenizer.chat_template_names";
    /// Beginning-of-sequence token id.
    pub const BOS_TOKEN_ID: &str = "tokenizer.bos_token_id";
    /// End-of-sequence token id.
    pub const EOS_TOKEN_ID: &str = "tokenizer.eos_token_id";
    /// The token string table.
    pub const TOKENS: &str = "tokenizer.tokens";
    /// The file's DECLARATION about prepending BOS. Not a computed rule.
    pub const ADD_BOS_TOKEN: &str = "tokenizer.add_bos_token";
    /// The file's DECLARATION about appending EOS. Not a computed rule.
    pub const ADD_EOS_TOKEN: &str = "tokenizer.add_eos_token";
}

/// One row: canonical key, format, that format's spelling.
pub type Row = (&'static str, Format, &'static str);

/// The vocabulary. Extend by adding rows.
pub const TABLE: &[Row] = &[
    (keys::CHAT_TEMPLATE, Format::Gguf, "tokenizer.chat_template"),
    (
        keys::CHAT_TEMPLATE_NAMES,
        Format::Gguf,
        "tokenizer.chat_templates",
    ),
    (
        keys::BOS_TOKEN_ID,
        Format::Gguf,
        "tokenizer.ggml.bos_token_id",
    ),
    (
        keys::EOS_TOKEN_ID,
        Format::Gguf,
        "tokenizer.ggml.eos_token_id",
    ),
    (keys::TOKENS, Format::Gguf, "tokenizer.ggml.tokens"),
    (
        keys::ADD_BOS_TOKEN,
        Format::Gguf,
        "tokenizer.ggml.add_bos_token",
    ),
    (
        keys::ADD_EOS_TOKEN,
        Format::Gguf,
        "tokenizer.ggml.add_eos_token",
    ),
    (
        keys::CHAT_TEMPLATE,
        Format::HuggingFace,
        "tokenizer_config.json:chat_template",
    ),
    (
        keys::BOS_TOKEN_ID,
        Format::HuggingFace,
        "tokenizer_config.json:bos_token_id",
    ),
    (
        keys::EOS_TOKEN_ID,
        Format::HuggingFace,
        "tokenizer_config.json:eos_token_id",
    ),
    (
        keys::ADD_BOS_TOKEN,
        Format::HuggingFace,
        "tokenizer_config.json:add_bos_token",
    ),
    (
        keys::ADD_EOS_TOKEN,
        Format::HuggingFace,
        "tokenizer_config.json:add_eos_token",
    ),
];

/// This format's spelling of a canonical key, or `None` if it has none.
#[must_use]
pub fn spelling(canonical: &str, format: Format) -> Option<&'static str> {
    TABLE
        .iter()
        .find(|(c, f, _)| *c == canonical && *f == format)
        .map(|(_, _, s)| *s)
}

/// The canonical key a format's spelling maps to, or `None`.
#[must_use]
pub fn canonical_for(spelling: &str, format: Format) -> Option<&'static str> {
    TABLE
        .iter()
        .find(|(_, f, s)| *f == format && *s == spelling)
        .map(|(c, _, _)| *c)
}
```

// crates/mlmf-meta/src/template.rs
//! Chat-template extraction.
//!
//! # What this does NOT return
//!
//! There is no `add_special_tokens` field and no method answering "should
//! I add BOS?". Spec section 9 clause 4.1 required `add_special_tokens =
//! false` unconditionally; that clause described one implementation's
//! pre-fix behaviour and is corrected in PR #12. **Whether to add BOS is a
//! property of the RENDERED string, which extraction does not produce**,
//! so it cannot be a static field of an extraction result.
//!
//! The file's own DECLARATION about it is a different thing and is
//! surfaced by [`crate::tokens`] — reporting what the file says is this
//! crate's job; computing what a runtime should do is not.

use alloc::string::{String, ToString};
use alloc::vec::Vec;

use mlmf_core::{MetaValue, MetadataSource};

use crate::vocab::{keys, spelling, Format};

/// One template: the default (`name: None`) or a named variant.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TemplateEntry {
    /// `None` for the default template, which is unnamed in every format
    /// that carries one.
    pub name: Option<String>,
    /// The template body, verbatim. Never parsed, never rendered.
    pub body: String,
}

/// Every template a source declared, plus what did not line up.
///
/// The two disagreement lists exist because section 5 rule 1 forbids
/// invisible loss: when the names array and the key set disagree, **that
/// disagreement is what the file says**, and reporting only one side would
/// discard a fact about the file.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct TemplateSet {
    /// Templates found, default first when present.
    pub entries: Vec<TemplateEntry>,
    /// Names listed in the names array with no corresponding body key.
    pub named_but_absent: Vec<String>,
    /// Body keys present but not listed in the names array. Their bodies
    /// ARE in `entries`; this list records that they were unannounced.
    pub present_but_unnamed: Vec<String>,
}

impl TemplateSet {
    /// The default template's body, if the source declared one.
    #[must_use]
    pub fn default_body(&self) -> Option<&str> {
        self.entries
            .iter()
            .find(|e| e.name.is_none())
            .map(|e| e.body.as_str())
    }

    /// Read every template `source` declared under `format`'s spellings.
    ///
    /// Enumerates from the key set and cross-checks against the names
    /// array, rather than trusting either alone.
    #[must_use]
    pub fn extract<S: MetadataSource + ?Sized>(source: &S, format: Format) -> Self {
        let mut out = Self::default();

        let Some(default_key) = spelling(keys::CHAT_TEMPLATE, format) else {
            return out;
        };

        if let Some(body) = source.get(default_key).and_then(MetaValue::as_str) {
            out.entries.push(TemplateEntry {
                name: None,
                body: body.clone(),
            });
        }

        // Named bodies live under `<default_key>.<name>`. Enumerate them
        // from the keys actually present.
        let mut prefix = String::from(default_key);
        prefix.push('.');

        let mut found: Vec<String> = Vec::new();
        for key in source.keys() {
            let Some(name) = key.strip_prefix(prefix.as_str()) else {
                continue;
            };
            if name.is_empty() {
                continue;
            }
            let Some(body) = source.get(key).and_then(MetaValue::as_str) else {
                continue;
            };
            found.push(name.to_string());
            out.entries.push(TemplateEntry {
                name: Some(name.to_string()),
                body: body.clone(),
            });
        }

        // Cross-check against the declared names, if the format has such a
        // key and the source declared it.
        let declared: Vec<String> = spelling(keys::CHAT_TEMPLATE_NAMES, format)
            .and_then(|k| source.get(k))
            .and_then(MetaValue::as_array)
            .map(|a| {
                a.iter()
                    .filter_map(MetaValue::as_str)
                    .map(ToString::to_string)
                    .collect()
            })
            .unwrap_or_default();

        for name in &declared {
            if !found.contains(name) {
                out.named_but_absent.push(name.clone());
            }
        }
        for name in &found {
            if !declared.contains(name) {
                out.present_but_unnamed.push(name.clone());
            }
        }

        out.named_but_absent.sort_unstable();
        out.present_but_unnamed.sort_unstable();
        out
    }
}

// crates/mlmf-meta/src/tokens.rs
//! Special-token declarations.
//!
//! Every field here is something a file SAID. Nothing here is something a
//! runtime SHOULD DO — see [`crate::template`] for why that distinction is
//! load-bearing rather than stylistic.

use alloc::string::String;

use mlmf_core::{MetaValue, MetadataSource};

use crate::vocab::{keys, spelling, Format};

/// A declared special token: the id, and its text when the vocabulary
/// contains that index.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SpecialToken {
    /// The id exactly as declared.
    pub id: u64,
    /// The token string, or `None` when the id is not a valid index.
    /// **The id survives either way** — it is what the file said.
    pub text: Option<String>,
}

/// What a source declared about its special tokens.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct SpecialTokens {
    /// The beginning-of-sequence token, if declared.
    pub bos: Option<SpecialToken>,
    /// The end-of-sequence token, if declared. May equal `bos` — eight
    /// corpus files declare the same id for both.
    pub eos: Option<SpecialToken>,
    /// What the file DECLARED about prepending BOS. `None` means the file
    /// did not say, which is not the same as saying `false`.
    ///
    /// **This is a declaration, not an instruction.** Whether a given
    /// render should prepend BOS depends on the rendered string.
    pub add_bos_declared: Option<bool>,
    /// What the file DECLARED about appending EOS. See `add_bos_declared`.
    pub add_eos_declared: Option<bool>,
}

impl SpecialTokens {
    /// Read the special-token declarations under `format`'s spellings.
    #[must_use]
    pub fn extract<S: MetadataSource + ?Sized>(source: &S, format: Format) -> Self {
        let lookup = |canonical: &str| spelling(canonical, format).and_then(|k| source.get(k));

        let vocab: Option<&[MetaValue]> = lookup(keys::TOKENS).and_then(MetaValue::as_array);

        let token = |canonical: &str| -> Option<SpecialToken> {
            let id = lookup(canonical).and_then(MetaValue::as_u64)?;
            let text = vocab
                .and_then(|v| usize::try_from(id).ok().and_then(|i| v.get(i)))
                .and_then(MetaValue::as_str)
                .cloned();
            Some(SpecialToken { id, text })
        };

        Self {
            bos: token(keys::BOS_TOKEN_ID),
            eos: token(keys::EOS_TOKEN_ID),
            add_bos_declared: lookup(keys::ADD_BOS_TOKEN).and_then(MetaValue::as_bool),
            add_eos_declared: lookup(keys::ADD_EOS_TOKEN).and_then(MetaValue::as_bool),
        }
    }
}

//! Assert the corpus, and name where it came from.
//!
//! Every expectation below was measured on 2026-09-03 against the corpus
//! at `MLMF_GGUF_CORPUS` (default `C:/Models/gguf-corpus`), workspace at
//! `origin/main` aeda952. A number without its subject becomes a claim
//! about the present the moment it is repeated, so the subject travels
//! with it.

use std::io::Write as _;
use std::path::{Path, PathBuf};

use mlmf_core::NOTICE_TOKEN;
use mlmf_meta::template::TemplateSet;
use mlmf_meta::tokens::SpecialTokens;
use mlmf_meta::vocab::Format;

fn corpus_root() -> Option<PathBuf> {
    let root =
        std::env::var("MLMF_GGUF_CORPUS").unwrap_or_else(|_| "C:/Models/gguf-corpus".to_string());
    let p = PathBuf::from(root);
    p.is_dir().then_some(p)
}

/// Skips when the corpus is genuinely absent, and fails instead when
/// `MLMF_CORPUS_REQUIRED=1`.
///
/// **The stated reason is itself a claim**, so it is one that can be
/// checked: this skips because the files are large binaries not kept in
/// the repository, which is verifiable by looking for them. It does NOT
/// skip for want of hardware, and it is deliberately not `#[ignore]`d — an
/// un-`#[ignore]`d test whose comment says "run with `-- --ignored`"
/// selects nothing, and libtest prints `0 ignored` either way, so a
/// filtered-out test and one that never existed look identical.
fn corpus_or_skip(test: &str) -> Option<PathBuf> {
    if let Some(p) = corpus_root() {
        return Some(p);
    }
    assert!(
        std::env::var("MLMF_CORPUS_REQUIRED").as_deref() != Ok("1"),
        "{test}: MLMF_CORPUS_REQUIRED=1 and no corpus at MLMF_GGUF_CORPUS"
    );
    let _ = writeln!(
        std::io::stderr(),
        "{NOTICE_TOKEN}: SKIPPED {test} -- no GGUF corpus (set MLMF_GGUF_CORPUS)"
    );
    None
}

fn gguf_files(root: &Path) -> Vec<PathBuf> {
    let mut out = Vec::new();
    let mut stack = vec![root.to_path_buf()];
    while let Some(dir) = stack.pop() {
        let Ok(rd) = std::fs::read_dir(&dir) else {
            continue;
        };
        for e in rd.flatten() {
            let p = e.path();
            if p.is_dir() {
                stack.push(p);
            } else if p.extension().is_some_and(|x| x == "gguf") {
                out.push(p);
            }
        }
    }
    out.sort();
    out
}
